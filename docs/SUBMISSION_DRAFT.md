# Nimiq Mini Apps Competition — Submission Draft

**Category:** Earn  
**Working description (under 250 words):**

LevelBreak Arena turns DeFi learning into a short, consequence-driven game. Players make choices in three simulated scenarios—stablecoin peg risk, impermanent loss, and high-yield sustainability—and see how each decision affects a virtual portfolio. At each level-up, a scripted agent-style requester presents a judgment task with evidence attached. Players can answer or skip; each accepted response earns a small fixed NIM reward.

A session is made available only after its NIM funding transaction has been verified on-chain. When the player finishes, the backend calculates rewards from the recorded responses and sends an ordinary NIM transfer from the operator treasury to the player's Nimiq wallet. The MVP uses a scripted requester and an operator-controlled treasury, not a live AI agent or trustless escrow, and discloses that limitation. Learning scenarios are simulated and never place real DeFi trades.

LevelBreak Arena uses Nimiq Pay wallet integration and NIM transactions as part of the core experience. It is designed for short, repeatable sessions that make DeFi risk concepts easier to understand through consequences rather than passive reading.
